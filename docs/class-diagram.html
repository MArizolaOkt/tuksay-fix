Ringkasan Relasi Antar Model
Model Relasi Target Keterangan
Customer hasMany CustomerOutlet, PurchaseOrder, Invoice, SuratJalan Satu customer bisa memiliki banyak outlet, PO, invoice, SJ
CustomerOutlet belongsTo Customer Outlet milik satu customer (cascade delete)
Barang hasMany PoItem, HargaBeli Satu barang muncul di banyak PO item; harga beli berubah tiap hari
PurchaseOrder belongsTo + hasMany + belongsToMany Customer, CustomerOutlet, PoItem, Invoice, DaftarBelanja PO memiliki banyak item; terhubung ke invoice & daftar belanja via pivot
PoItem belongsTo PurchaseOrder, Barang Item baris dalam PO; qty desimal mendukung 0.5, 1.25, dll
HargaBeli belongsTo Barang Satu harga beli per barang per tanggal (UNIQUE constraint)
DaftarBelanja hasMany + belongsToMany DaftarBelanjaItem, PurchaseOrder Rekap belanja harian; pivot ke PO melalui daftar_belanja_po
SuratJalan belongsTo Customer, CustomerOutlet SJ per outlet; auto-generate no_sj format SRTJ-XXX-DDMMYYYY-NNNNN
Invoice belongsTo + belongsToMany Customer, PurchaseOrder Invoice per customer; terhubung ke PO via pivot invoice_purchase_orders
BiayaOperasional — — Standalone; digunakan untuk perhitungan Net Profit di laporan P&L
